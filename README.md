# Portal institucional — I.E. Indígena N.º 4, Sede Majayutpana

Primera versión estática para GitHub Pages.

## Contenido
- `index.html`: página completa, adaptable a móviles y ordenadores.
- `assets/escudo.jpeg`: escudo institucional suministrado.
- No requiere instalar dependencias ni compilar archivos.
- Incluye navegación, secciones institucionales, recursos y un asistente de demostración local.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub, por ejemplo `portal-majayutpana`.
2. Sube `index.html` a la raíz del repositorio.
3. Abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/(root)`, y guarda.
6. Espera a que GitHub Pages publique el sitio y abre la URL que aparece en esa pantalla.

## Antes de publicar oficialmente
- Confirmar el nombre oficial, logotipo, colores y datos de contacto.
- Añadir historia, misión, visión y contenido cultural con validación de la comunidad.
- Sustituir los avisos de ejemplo por noticias y fechas confirmadas.
- Usar únicamente fotografías con autorización, especialmente cuando aparezcan menores.
- El asistente es una demostración local; no está conectado a un modelo de IA real.
- El formulario de contacto no envía ni guarda datos. Para recibir mensajes debe integrarse con un servicio aprobado por la institución.
- No publicar información personal o sensible de estudiantes.

## Personalización
Edita `index.html` con cualquier editor de texto o desde GitHub. Busca los textos provisionales (por ejemplo, “Agregar correo oficial autorizado”) y reemplázalos por información confirmada.
